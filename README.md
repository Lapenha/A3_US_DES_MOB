# A3_US_DES_MOB

Jogo da velha educativo sobre animais, desenvolvido em React e Bootstrap para o projeto academico de usabilidade.

## Destaques

- placar por jogador e contagem de empates;
- leaderboard da sessao persistido no `localStorage`;
- restauracao da partida ao atualizar a tela;
- animacoes nas pecas, tabuleiro e cards;
- curiosidades educativas carregadas por requisicao HTTP;
- interface responsiva com heuristicas de Nielsen aplicadas.

## Tecnologias

- React
- Vite
- Bootstrap
- ESLint

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
```
